# 範圍決策記錄｜2026-11-24：由 v2 收斂為 v3

## 原因

先前 v2 將「路線級污染熱點、低污染導航、獨立道路驗證」視為正式必做。但公開的環境部 AQX_P_432、AQX_P_488、AQX_P_13 與 AQX_P_07 主要提供**監測站尺度**資訊，尚無可直接證明每條道路時空 PM2.5 的官方資料及獨立驗證集，若堅持必做可能產生無證據排名或無法驗收的功能。

本次依 2026-11-24 實際可檢視的官方資料，將功能分級：

- **P0 核心必做**：站點 AQI、歷史 PM2.5、1／3／6h ML、官方規則、Agent、時間比較、地圖、濃度×時間估算、來源及雙軌實驗。
- **P1 延伸**：SHAP、手動活動記錄彙總。
- **正式排除**：路段空污熱點／可靠低污染路線排行、個人真實吸入劑量、醫療風險診斷、保證減害百分比。

## v2 → v3 功能對照

| v2 類別 | v3 決策 | 備註 |
|---|---|---|
| M1 測站級、短期預測、Agent | **保留 P0** | 需 API Key 與歷史資料實際盤點 |
| M2 替代時段與活動估算暴露 | **保留 P0、嚴格標示測站尺度** | 不等於個人吸入劑量 |
| M2 SHAP／手動每日累積 | **調為 P1** | 方法成熟、可在核心完成後增加 |
| M3 候選路線、路段熱點及低污染推薦 | **排除核心交付** | 測站資料不足以支撐可靠道路排名 |
| Track C 路線獨立驗證 | **取消正式評估軌** | 僅保留活動指數確定性單元測試 |
| Track A／B | **保留** | 預測與 Agent 兩軌可重現驗證 |
