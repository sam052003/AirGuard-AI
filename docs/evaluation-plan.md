# AirGuard AI｜實驗與驗收設計（可實作版）

## Track A — PM2.5 時序模型

- **樣本**：經品質盤點之臺中官方站點逐時 PM2.5（日期待確認，不能預填樣本數）。
- **目標**：未來 1、3、6h 原始 PM2.5（μg/m³）；特徵只使用預測起點時可得資訊。
- **對照**：Persistence `y(t+h)=y(t)`；Seasonal Naive `y(t+h)=y(t+h−24h)`（取樣時間不晚於 t）。
- **候選模型**：Ridge、Random Forest、XGBoost，不預設哪種最佳。
- **驗證**：按時間連續切分約 70／15／15；Rolling-origin 於開發段；test 一次性。特徵補值／標準化在訓練期擬合。
- **報告**：MAE、RMSE、Skill Score = `1−MAE_model/MAE_persistence`；分站點、時距、季節與污染高峰，並報有效樣本數、缺值規則與模型版本。

## Track B — Agent／活動決策

固定至少 30 個案例（建議 6 類 × 5 題）：

| 類型 | 案例與通過準則 |
|---|---|
| B1 正常活動 | 正確解析測站／活動／未來 6h 內時段，調用適當工具 |
| B2 敏感族群 | 依官方 AQI 指引提供保守資訊，不做醫療診斷 |
| B3 時間／地理歧義 | 同名站、地點不明、超過 6h：追問或明示範圍 |
| B4 缺值／過期 | 不拿舊快取聲稱目前；不把缺值視為 0 |
| B5 系統失效 | API timeout、模型無法使用、無資料：可追溯降級 |
| B6 數值與引用 | AQI≠預測 PM2.5；引用支持；單位與來源正確 |

指標：工具選擇正確率、必要來源完整率、官方規則一致率、安全降級率、P50／P95 回應時間；同一資料版本比較「Rule-only」與「Agent＋ML＋Rules」。

## 決策指數單元測試（不等於道路 Track C）

- **公式**：`ExposureIndex=Σ(Concentration_μg_m3×Duration_h)`，單位 μg·h/m³。
- **測試**：一段／多段加總、重複區間、缺值時段、部分涵蓋、0 小時、不合理負值、不同站點不可默默合併。
- **評估界線**：這是確定性程式結果，不代表醫學效益或個人真實吸入量；不得列「降低暴露幾%」除非有獨立介入實驗。
