# 實驗設計與驗收方法

本計畫將 PM2.5 預測準確度（評估 A）與 Agent 決策可靠性（評估 B）分開評估；**所有結果仍待實際執行**。

## 評估 A：時間序列預測

**標的**：官方測站逐小時原始 PM2.5 濃度（μg/m³），預測 `h = 1 / 3 / 6` 小時。  
**區間**：資料品質確認後，優先以 2024–2026 可取得資料；依時間連續切分約 `70/15/15`。  
**基準模型（Baseline）**：Persistence `ŷ(t+h)=y(t)`；Seasonal Naive `ŷ(t+h)=y(t+h−24h)`（必須已可得）。  
**候選模型**：Ridge、Random Forest、XGBoost；LSTM 為延伸。  
**評估流程**：train 開發、validation／rolling-origin 調參、test 最終一次性評估。  
**評估指標**：MAE、RMSE、相對 Persistence 的 skill、分站／分時距／污染事件樣本數與誤差。  
**模型可解釋性**：SHAP 重要特徵與典型案例檢視，不宣稱因果關係。

重點檢查：特徵只能使用在 forecast origin 當時可得資料；rolling 特徵不可越過 t；訓練內擬合填補與標準化；歷史版本時間不明者不得冒稱嚴格 point-in-time 回測。

## 評估 B：Agent 與活動建議

**最低固定情境：30 題**。建議 6 類 × 各 5 題，正式題內容與驗收答案在執行前凍結：

| 類別 | 例子 | 驗收重點 |
| --- | --- | --- |
| A：一般族群戶外活動 | 同站 1–6h 跑步時段 | 解析、工具選擇、來源 |
| B：敏感族群 | 指定族群與官方指引 | 規則一致與保守表述 |
| C：時段／站點歧義 | 同名站、超出 6h | 澄清或 out_of_horizon |
| D：來源／資料品質 | 缺失、異常、過期 | 不能假裝資料合格 |
| E：工具故障 | API timeout、空集合、模型不可用 | 明確區分失敗、空結果與降級 |
| F：引用／安全 | 模型 PM2.5 冒稱 AQI、過度健康建議 | 數值／語意／指引檢查 |

**指標**：工具選擇正確率、必要來源完整率、官方規則一致率、安全降級通過率、回應時間 median/P95、人工質性審查。各指標需公開分母與不適用情況，不先填入虛構測試結果。

**對照與消融實驗**：Rule-only 固定流程、Agent+ML+Rules；另外分別移除領域規則、不確定性提示或風場特徵，觀察功能差異。實驗時固定資料版本、情境與調用預算，分開歸因模型改善和 Agent 改善。

## 成果呈現

- 每個測站及 horizon 的 Baseline／Model MAE、RMSE 表。
- 正式測試樣本、模型版本、特徵與時間切分清單。
- 30 題 Agent 情境測試集、預期工具及通過準則、逐題狀態。
- 來源證據、資料品質、API 故障與時距超限的案例分析。
- 如實報告無改善、限制、成本及後續研究方向。
