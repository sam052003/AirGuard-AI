## P0 驗收門檻

- **資料**：至少一個臺中官方測站及一段經品質核對、可重現的逐時 PM2.5 歷史，提供來源、樣本數、缺失率、時間窗、單位及資料雜湊；站數及年份不預先捏造。
- **ML**：1／3／6h Persistence 與候選模型、固定時間切分、Rolling-origin、每個時距與測站的 MAE／RMSE／Skill；負結果如實報告。
- **Agent**：至少 30 題固定測試，事先記錄工具選擇、來源、規則、例外預期結果；不得以 LLM 裸估數字。
- **活動決策**：只在已驗證的時間範圍比較；AQI 官方當前分級與預測 PM2.5 必須分開；污染相近與區間不確定時可拒絕排名。
- **估算指數**：`Σ(濃度 μg/m³ × 時長 h)` 可由測試資料重算，對缺值顯示資料不足，不能承諾健康安全。
- **系統展示**：可在 Web 頁面查詢與檢視站點、官方 AQI、歷史／預測、活動比較、資料時間、證據與限制；含 API 故障／快取降級畫面。

## P1 驗收

- **SHAP**：有一致模型版本的局部／整體解釋，清楚標示特徵貢獻 ≠ 因果。
- **活動記錄**：只加總已知濃度與已知時長，清楚列出未覆蓋的時間、測站假設；自訂比較值不可稱官方安全標準。

## 排除與阻擋條件

1. 不輸出「A 路線比 B 路線更乾淨」或街道熱點；僅能在站點尺度顯示官方監測與模型結果。
2. 不產生 6h 範圍之外的自建 PM2.5 精確時點預測；較長期官方預報僅可做不同來源／空間尺度的背景參考。
3. 沒有 API Key、API 失敗或缺最新資料時，不能把舊快取標示成即時；缺值不能填 0 表示乾淨。
4. 不提供醫療診斷、實際吸入劑量、因果證明或減少暴露保證百分比。
5. 沒有實測 ML、Agent 指標或可操作 Demo 前，README、報告和簡報中一律標示「規劃／待驗證」。
