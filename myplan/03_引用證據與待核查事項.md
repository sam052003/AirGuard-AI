# AirGuard AI｜引用證據與尚待核查事項（v3）

| 主張 | 可核實來源 | 研究使用方式 |
|---|---|---|
| 2019 年全球室外空污約 420 萬過早死亡 | [WHO Fact Sheet](https://www.who.int/news-room/fact-sheets/detail/ambient-(outdoor)-air-quality-and-health) | 研究動機，不能寫 2021 年估計 |
| 臺灣全國 PM2.5 年平均 2019 年 16.2 → 2025 年 12.8 μg/m³ | [環境部官方新聞](https://enews.moenv.gov.tw/moenv-news/zh-tw/News/1844) | 約改善 21%；不能推及個別城市街道 |
| 官方 AQI 多污染物與活動指引 | [環境部 AQI](https://airtw.moenv.gov.tw/cht/Information/Standard/AirQualityIndicatorNew.aspx) | 正確分級、版本化；不能自建未來官方 AQI |
| MOENV API 需會員金鑰 | [API 取得說明](https://data.moenv.gov.tw/paradigm) | 金鑰只存 Server Secrets |
| 逐時 PM2.5 有資料來源 | [AQX_P_13](https://data.moenv.gov.tw/dataset/detail/AQX_P_13) | 仍需下載盤點可用月份及測站品質 |
| SHAP 特徵解釋 | [Lundberg & Lee (2017)](https://proceedings.neurips.cc/paper_files/paper/2017/hash/8a20a8621978632d76c43dfd28b67767-Abstract.html) | 僅模型特徵貢獻，不是因果 |

**待實測**：每個臺中測站資料可用小時數、季節分布、空值率、正式 MAE、Agent 指標、動態 API 延遲／配額與使用者回應時間。  
**不能引用為本組成效**：任何外部研究的低污染路線暴露降幅、未經驗證的個人吸入量數字、未完成測試的 Agent 成功率。
