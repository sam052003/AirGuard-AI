# AirGuard AI｜研究依據與系統規劃 v3

## 研究問題

**RQ1**：在可取得逐時 PM2.5 的臺中測站，Ridge／Random Forest／XGBoost 相較 Persistence／Seasonal Naive 能否改善 1／3／6h 預測？  
**RQ2**：受控 AI Agent 搭配官方來源工具與領域規則，是否比直接生成式問答更可靠地回覆活動決策？  
**RQ3**：將資料新鮮度、不確定性及濃度×時間估算加入介面，能否降低超時距、不當數字與活動建議的錯誤？

## 資料與研究背景

[WHO](https://www.who.int/news-room/fact-sheets/detail/ambient-(outdoor)-air-quality-and-health) 2019 年全球室外空污負擔、[環境部](https://enews.moenv.gov.tw/moenv-news/zh-tw/News/1844) 2019→2025 PM2.5 年平均改善，屬研究動機；不能當成系統模型能力。原始資料為官方即時 [AQX_P_432](https://data.moenv.gov.tw/dataset/detail/AQX_P_432)、歷史 [AQX_P_488](https://data.moenv.gov.tw/dataset/detail/AQX_P_488)、逐時 [AQX_P_13](https://data.moenv.gov.tw/dataset/detail/AQX_P_13)、站點 [AQX_P_07](https://data.moenv.gov.tw/dataset/detail/AQX_P_07) 與 [AQI 活動指引](https://airtw.moenv.gov.tw/cht/Information/Standard/AirQualityIndicatorNew.aspx)。

## 系統功能

以 [SRS v3](../docs/requirements.md) 的 P0 核心必做為基礎；P1 SHAP／活動記錄為擴充；**路段空污熱點與導航排序不在本次最終必做範圍**。應用只到**監測站尺度**，時段只到經驗證的 1／3／6h 預測窗；不能把 PM2.5 預測當完整官方 AQI。

## 技術及評估

- 受控 Planner Agent、官方來源工具及固定規則、失效降級，不把任何來源內容當可執行指令。
- Chronological 70／15／15 + Rolling-origin；MAE／RMSE／Skill Score；分站、時距及污染事件分組。
- ≥30 Agent 固定案例，量測工具選擇正確率、引用完整率、規則一致率、降級與延遲。
- 可核算指數 `Σ(C×Δt)` 的單位 μg·h/m³、資料覆蓋與未知時段；不計個人實際吸入劑量。

## 已知風險與取捨

MOENV API 需 Key、歷史月份覆蓋待盤點；可先用官方歷史下載建立固定回測，並使用具日期標籤之快取 Demo。道路級污染需要更多來源與獨立驗證，因此避免造成超出現有資料的研究承諾。詳見 [可行性審查](../docs/feasibility-audit.md)。
