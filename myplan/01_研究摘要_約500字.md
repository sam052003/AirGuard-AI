# AirGuard AI｜研究摘要（v3 約 500 字）

空氣污染仍影響民眾的戶外活動安排。WHO 估計 2019 年全球室外空氣污染造成約 420 萬人過早死亡；臺灣環境部公布 PM2.5 全國年平均濃度由 2019 年 16.2 降至 2025 年 12.8 μg/m³，顯示長期改善，但年度平均並不能直接回答個別監測站、特定時段的活動風險。現有資料平台可提供官方 AQI 與監測值，使用者仍需自行解讀時段、活動強度及資料有效性。

本研究提出 **AirGuard AI：智慧空氣品質預測與生活決策代理人**，以臺中具足夠歷史資料的官方監測站為試點，整合環境部即時 AQI、歷史逐時 PM2.5、站點座標與官方活動指引。系統以 Persistence、Seasonal Naive 為基線，比較 Ridge、Random Forest、XGBoost 的未來 1、3、6 小時 PM2.5 預測，以時間切分及 Rolling-origin 避免資料洩漏，透過 MAE、RMSE 與 Skill Score 報告實際誤差。受約束的 AI Agent 解析使用者情境、調用資料與模型工具、檢查來源及時間，在資料有效時比較戶外活動候選時段，並提供測站濃度與活動時長的積分估算及不確定性。

本研究另以至少 30 個固定 Agent 情境檢驗工具選擇、引用正確、官方規則一致與 API 失效降級。SHAP 與手動活動記錄可視開發進度延伸。由於公開測站資料不足以獨立證明道路級污染差異，本期末系統不提供低污染路線排名、個人真實吸入劑量或醫療診斷。預期成果是一套具可重現模型測試、來源追溯與保守決策規則的網頁原型；所有成效均待後續實驗驗證。
